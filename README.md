# SkillSwap Mini Project

## Requirements
- Node.js LTS + npm
- MySQL Server and MySQL Workbench
- IntelliJ IDEA or VS Code

## Setup
1. Run `database/schema.sql` in MySQL Workbench.
2. Copy `server/.env.example` to `server/.env` and set your MySQL password.
3. In a terminal: `cd server` then `npm install` then `npm run dev`.
4. In another terminal: `cd client` then `npm install` then `npm run dev`.
5. Open the Vite URL printed in the terminal, usually http://localhost:5173.

Register two accounts. Add reciprocal teach/learn skills to both accounts to demonstrate matching.

This is a simple educational starter, not a production-ready deployment.
